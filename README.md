# 🛒 E-Commerce Frontend Project

Full e-commerce frontend project — from UX/UI design in Figma to implementation with HTML, CSS, and React.  
Includes API integration for payment methods and user interaction.

---

## Overview

This repository contains the **frontend development** of an e-commerce platform.  
The project was designed from scratch in Figma, implementing responsive design principles, accessibility, and modern web technologies.

---

## UX/UI Design

- Tool: **Figma**
- File: [View Figma Prototype](./docs/figma/figmaLink.md)
- Focus areas:
  - Clean and minimalistic visual identity
  - Seamless checkout flow
  - Product filtering and search functionality
  - Mobile-first responsive layout
