# 🎨 Figma Prototype

This document contains the link and description of the **UX/UI design** created in Figma for the e-commerce frontend project.

---

## Overview

The Figma prototype defines the **visual identity**, **layout**, and **interaction flow** of the website.  
It includes all key pages of the e-commerce, both in **desktop (1440x1024)** 

The design focuses on:
- Simple navigation and intuitive product exploration.
- Visual hierarchy for highlighting key sections.
- Clean, modern interface with a natural color palette (greens and oranges).
- Smooth transitions and consistent spacing.

## Pages Included

| Page | Description |
|------|--------------|
| **Home** | Hero section with main banner, categories, and featured products. |
| **Product List** | Grid of products with filters and search functionality. |
| **Product Detail** | Page showing images, price, description, and “Add to Cart” button. |
| **Cart & Payment** | Cart summary, shipping details, and payment options. |
| **Comments** | Spacee for testimons of the users . |

---

## Design System

| Element | Description |
|----------|--------------|
| **Typography** | Poppins / Inter — clean, rounded sans-serif for modern feel. |
| **Colors** | Greens (#4CAF50) and Oranges (#FF9800) for organic branding. |
| **Buttons & Inputs** | Rounded edges, hover states with soft shadows. |
| **Icons** | Outline style, consistent visual weight. |


---


## 🧩 Prototype Interactions

- Button hover states  
- Page transitions  
- Add to cart → Cart page  
- Checkout → Confirmation  
- Return to Home  

---

## 🧑‍🎨 Designer Notes

The design aims to:
- Highlight the product photography and colors.
- Maintain visual consistency across all breakpoints.
- Offer a friendly and organic style aligned with a plant-based e-commerce brand.
